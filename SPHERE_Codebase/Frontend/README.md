# SPHERE Frontend Dashboard

A monolithic, ultra-fast React dashboard built with Vite, Tailwind CSS, and Lucide React. 
It simulates AI ingestion and maps the processed JSON output directly into interactive UI cards.

## 🚀 Virtualization for Massive Scale
To handle rendering up to 10,000+ unstructured civil engineering requirements simultaneously without freezing the browser, this dashboard implements **React Virtual Scrolling** using eact-window and eact-virtualized-auto-sizer. Only the exact UI cards actively visible on your screen are rendered, ensuring silky smooth performance regardless of dataset size.

## Running locally

pm install

pm run dev

## Architecture
- src/App.jsx: Main application logic, UI, and Virtual List implementation.
- src/utils/mockData.json: Hardcoded requirement payload generated by the Python backend.
